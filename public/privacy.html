Privacy policy

Last updated: 2026-10-10. Publisher: Real Dental Costs (realdentalcosts.com). This policy covers the Real Dental Costs plugin and connector for AI assistants (ChatGPT, Claude and other clients of the Model Context Protocol), served from https://mcp.realdentalcosts.com.

Personal data

None is collected. The tools never ask for a name, age, date of birth, ZIP code, address, insurer or plan name, member ID, health information, phone number or email address, and they have no account, login, cookie or tracker.

What the server receives

Only the arguments of each tool call: a US state code, a city or county name, a procedure id or CDT code, quantities, quoted amounts in US dollars, a coverage category (none, adult Medicaid, private, Medicare Advantage, discount plan) and a language (en or es). They are used in memory to look up published figures, then discarded with the response. They are not saved, sold or shared.

Usage counts

The server writes an aggregate count of calls per tool and per UTC day. It contains no tool argument, no IP address, no user agent and no other data about the person asking. The hosting provider keeps its own technical request logs under its terms.

Links

Answers link to pages of realdentalcosts.com with a utm_source tag naming the assistant (for example chatgpt or claude), so the site can count visits per assistant. Visiting the site is governed by the site's own privacy policy.
